GOA EVENTS — WEBSITE PACKAGE

Included:
- index.html — homepage
- venues.html — venue directory with search/filter
- caterers.html — caterer directory
- services.html — event services
- booking.html — event enquiry form
- styles.css — responsive styling
- script.js — search, mobile menu and demo form behavior

IMPORTANT:
This is a static website. The booking form is a demo until connected to a real form service/database.

EASIEST WAY TO PUT IT ONLINE:
1. Upload this folder to a static host such as GitHub Pages, Netlify, or Vercel.
2. Open index.html as the homepage.
3. Later connect the booking form to Google Forms/Sheets or a real database.

GOOGLE SITES:
Google Sites does not directly import a multi-page HTML website as a template. You can use this package as the design/reference, or embed supported content. For the full custom site, publish these files on a static host.

DEMO DATA:
The venue and caterer names/prices are placeholders and should be replaced with real vendors only after you have permission/partnerships.
